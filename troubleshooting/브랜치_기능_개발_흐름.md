### 주의 
깃허브의 본인의 작업 내용을 반영할 때, 해당 작업 흐름을 참고하되 신뢰하지 말고, AI한테 잘 물어보면서 진행하세여~^^

## 작업 흐름
```
main에서 작업 브랜치 생성
→ 기능 개발
→ commit
→ push
→ Pull Request 생성
→ 코드 리뷰 및 테스트
→ main에 병합
→ 원격 작업 브랜치 삭제
→ 로컬 작업 브랜치 삭제
```
## 명령어
```bash
git switch main
git pull origin main

git switch -c feature/example
# 작업 후
git add .
git commit -m "Add example feature"
git push -u origin feature/example
```
## Pull Request가 병합된 후:
```
git switch main
git pull origin main
git branch -d feature/example
git fetch --prune
```


### 메인 이동-> 끌어오기 -> 서브 병합

```
# 1. 현재 작업 내용 커밋
git add .
git commit -m "Add commit frequency"

# 2. 로컬 main으로 이동
git switch main

# 3. 원격 main의 최신 내용을 로컬 main에 반영
git pull --rebase origin main

# 4. feature 브랜치를 로컬 main에 병합
git merge feature/commit-frequency

# 5. 병합된 main을 원격 저장소에 업로드
git push origin main
```

### 원격 저장소와 완전 동기화
```
 git reset --hard origin/main
```
