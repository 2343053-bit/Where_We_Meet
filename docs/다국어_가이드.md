# 다국어 가이드 (한국어 / 영어)

이 문서는 **화면에 보이는 글자를 한국어·영어로 바꿀 수 있게 쓰는 방법** 을 정한 규칙이다.
파일 배치·이름 규칙은 [`기능_추가_가이드.md`](./기능_추가_가이드.md) 를 그대로 따르고, 이 문서는 "글자를 쓰는 법" 만 다룬다.

## 0. 기본 원칙

> **화면에 보이는 글자는 코드에 직접 쓰지 않는다. "키" 를 쓰고, 문장은 사전에 둔다.**

- 사전은 언어마다 하나씩 있다. 같은 키에 언어별 문장을 적는다.
- HTML 은 `#{키}`, JS 는 `t('키')` 로 꺼낸다.
- 숫자·이름이 들어가는 문장은 이어 붙이지 않고 `{0}` 빈칸을 쓴다. (언어마다 어순이 다르다)

```text
❌  <button>공유</button>                     el.textContent = '승용차 ' + 분 + '분';
✅  <button th:text="#{panel.share}">공유</button>   el.textContent = t('route.minutes', 분);
```

## 1. 한눈에 보기

```text
사용자가 상단 [English] 클릭  →  ?lang=en
    ↓
config/LocaleConfig.java      ← 언어를 en 으로 바꾸고 쿠키(lang)에 1년 기억. 기본은 한국어
    ↓
main.html 렌더링 (Thymeleaf)
    ├─ #{키}                   → messages_en.properties 에서 찾아 HTML 에 넣음
    └─ fragments/jsMessages    → JS 용 문장도 번역해서 window.APP_DATA.messages 에, 지금 언어는 APP_DATA.lang 에 넣음
    ↓
js/main.js
    └─ initMessages(appData.messages, appData.lang)   ← util/i18n.js 에 사전과 언어를 넣음 (다른 모듈보다 먼저)
          ↓
       각 모듈에서 t('키')               ← 지금 언어의 문장
```

## 2. 파일 지도

```text
src/main
├── java/com/springboot/config
│   └── LocaleConfig.java              # ?lang= 으로 언어 변경, 쿠키에 기억, 기본 한국어
└── resources
    ├── messages.properties            # 사전 - 기본(한국어)
    ├── messages_en.properties         # 사전 - 영어
    ├── templates/fragments
    │   ├── langSwitch.html            # 상단 "한국어 | English" 버튼 (header.html 에서 불러옴)
    │   └── jsMessages.html            # JS 에서 쓸 문장을 번역해 APP_DATA.messages 로 전달
    └── static/js/util
        ├── i18n.js                    # initMessages(사전, 언어), t('키', 값...), getLang()
        └── langSwitch.js              # 결과 화면에서 언어를 바꾸면 폼을 다시 제출해서 결과 유지
```

## 3. 키 이름 규칙

| 규칙 | 예 |
| --- | --- |
| `영역.내용`. 각 부분은 소문자로 시작하는 camelCase | `header.login`, `route.minutes`, `panel.share`, `participant.namePlaceholder` |
| 영역은 기능·파일 이름 | `header`(상단 메뉴), `participant`(참가자 칸), `panel`(장소 패널), `route`(경로), `location`(현재 위치) |
| 페이지 제목은 `title.<페이지>` | `title.main`, `title.login`, `title.signup` |
| 사전 안에서는 영역별로 묶고 `# ── 영역 (파일) ──` 주석을 단다 | `# ── 카페 클릭 → 경로 (map/carRoutes.js) ──` |

## 4. HTML(템플릿)에서 쓰기

| 쓰임 | 모양 |
| --- | --- |
| 태그 안 글자 | `<span th:text="#{panel.phone}">전화번호</span>` |
| placeholder | `<input th:placeholder="#{participant.namePlaceholder}">` |
| 다른 속성 | `th:title="#{...}"`, `th:alt="#{...}"`, `th:value="#{...}"` |
| 빈칸이 있는 문장 | `th:text="#{participant.legend(${num})}"` → 사전: `participant.legend=참가자 {0}` |
| 페이지 제목 (head 조각) | `th:replace="~{fragments/head :: common(#{title.login})}"` |
| 서버(Java)가 보내는 오류 문구 | 서비스는 예외에 문장 대신 **키** 를 담고 (`throw new IllegalArgumentException("member.nicknameTaken")`), 화면은 `th:text="#{${errorMessage}}"` 로 번역한다. (`#{${변수}}` = 변수 값을 키로 써서 사전에서 찾기) |

- 태그 안에 남겨 둔 한국어(`>전화번호<`)는 **미리보기용 기본값** 이다. 실제 화면에서는 `th:text` 가 덮어쓴다.
- `#{...}` 는 번역 문장, `${...}` 는 서버 값이다. 섞어 쓸 때 헷갈리지 않게 주의한다.

## 5. JS 에서 쓰기 (3단계)

JS 파일은 Thymeleaf 를 거치지 않아서 `#{키}` 를 직접 못 쓴다. 그래서 서버가 번역해서 배달해 준 문장을 꺼내 쓴다.

**1) 두 사전에 키 추가**

```properties
# messages.properties
location.denied=현재 위치 권한을 허용해주세요.
# messages_en.properties
location.denied=Please allow location access.
```

**2) `templates/fragments/jsMessages.html` 에 한 줄 추가** (안 하면 JS 로 넘어가지 않는다)

```js
'location.denied': /*[[#{location.denied}]]*/ '',
```

**3) 모듈에서 import 후 사용** (경로는 그 파일 기준, 가이드 J8)

```js
import { t } from '../util/i18n.js';

statusElement.textContent = t('location.denied');
html += names[j] + ': ' + t('route.minutes', 27);   // 사전의 {0} 자리에 27
```

- `t()` 는 사전에 없는 키를 받으면 **키를 그대로 돌려준다.** 화면에 `location.denied` 같은 글자가 보이면 2) 를 빠뜨린 것이다.
- `t()` 를 쓰는 모듈은 `main.js` 의 `initMessages(appData.messages, appData.lang)` 보다 **뒤에** 실행돼야 한다. 지금은 `main.js` 맨 앞에서 넣고 있으니 그대로 두면 된다.
- 문장 번역이 아니라 **언어에 따라 보여 줄 값 자체가 다를 때** 는 `getLang()` (지금 언어 코드 `"ko"` / `"en"`) 으로 나눈다. 예) 장소 종류: 한국어는 카카오의 자세한 분류, 영어는 `category.코드` 번역 (`map/placePanel.js` 의 `getCategoryText`)

## 6. 번역하지 않는 것

| 무엇 | 이유 |
| --- | --- |
| 코드 주석, `console.log` / `console.error` 문구 | 개발자만 보는 글자 |
| 카카오가 주는 장소 이름·주소, 지도 그림 안의 지명 | 카카오 데이터라 한국어로만 온다 |

## 7. 주의할 점

| # | 주의 | 이유 / 증상 |
| --- | --- | --- |
| I1 | 키는 **두 사전에 항상 같이** 추가한다 | 영어 사전에 빠지면 영어 화면에 한국어가 나온다 |
| I2 | HTML 에서 `#{키(값)}` 처럼 **빈칸을 채우는 문장에 작은따옴표 `'` 가 있으면 `''` 로 두 번** 쓴다 | Spring 문장 형식(MessageFormat) 규칙. JS 의 `t()` 는 상관없다 |
| I3 | `th:inline="javascript"` 스크립트(`jsMessages.html` 포함)의 **주석에 대괄호 두 개 문법을 쓰지 않는다** | 주석 안이라도 Thymeleaf 가 실행해서 에러가 난다 |
| I4 | 사전 파일은 UTF-8 로 저장한다 | VS Code 기본값. 다른 편집기에서 열 때만 확인 |
| I5 | 화면에 `??키_en??` 가 보이면 사전에 그 키가 없는 것이다 | HTML 쪽 누락 표시 |
| I6 | 결과 화면에서 언어를 바꾸면 **폼을 다시 제출** 한다 (`util/langSwitch.js`) | 폼에 새 입력칸을 추가하면 그 값도 같이 다시 보내진다. 서버가 받아도 괜찮은지 확인한다 |

## 8. 언어를 하나 더 추가하려면 (예: 일본어)

1. `messages_ja.properties` 를 만들고 모든 키를 번역한다.
2. 두 사전과 새 사전에 `lang.ja=日本語` 를 추가한다.
3. `fragments/langSwitch.html` 에 `<a href="?lang=ja" data-lang="ja" th:text="#{lang.ja}">日本語</a>` 한 줄을 추가한다.

`LocaleConfig.java` 와 JS 는 고칠 필요가 없다.
